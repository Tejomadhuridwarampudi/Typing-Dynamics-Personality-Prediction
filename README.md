✨ Typing Dynamics Personality Prediction

This project is an AI-powered typing behavior analysis tool built using Streamlit.
It studies how you type — such as your speed, rhythm, pauses, consistency, and error patterns — to generate personality insights based on typing dynamics.

The app provides real-time metrics, interactive visualizations, and AI-generated personality traits, offering a unique blend of behavioral analysis and user-friendly design.

🚀 Features
⌨️ Typing Behavior Analysis

Tracks keystroke patterns

Measures pauses, typing speed, and rhythm

Analyzes error and backspace behavior

🧠 Personality Prediction

Generates five personality trait scores:

Openness

Conscientiousness

Extraversion

Agreeableness

Neuroticism

Displays your dominant personality category

▶️ How to Run the Project

Install dependencies:

pip install -r requirements.txt


Run the application:

streamlit run app.py


The app will open in your browser automatically.

🌟 How It Works

User types naturally in the text box.

System captures:

Timestamp of each keystroke

Backspaces

Typing length and speed

Metrics like WPM, pause variability, rhythm consistency & error rate are calculated.

AI logic generates personality profiles.

Charts visualize the typing dynamics.

🧬 Personality Traits Explained

Openness: Creativity and curiosity

Conscientiousness: Organization and discipline

Extraversion: Sociability and energy

Agreeableness: Cooperation and empathy

Neuroticism: Emotional sensitivity and stability
